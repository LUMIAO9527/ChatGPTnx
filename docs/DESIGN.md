# 面板与状态设计

原生窗口和 HTML 共用 `src/nx/design.py` 的面板尺寸与列表分页上限。颜色、字体、间距、阴影和控件圆角比例统一由 `src/ui/tokens.css` 提供；磨砂玻璃与纯色只改变材质令牌。

## 组件尺寸

| 组件 | 高度 | 圆角和间距 |
| --- | --- | --- |
| 面板 | 458，宽 312 | R16 |
| 账号信息卡 | 112 | R16；正常额度和登录恢复提示共用额度区域 |
| 首页账号行 | 44 | 高度乘 3/8；阴影保留外扩空间 |
| 详情页操作行 | 40 | 高度乘 3/8；相邻行间隔 6 |
| 设置与展开列表行 | 42 | 高度乘 3/8；展开行与所属入口等高 |
| 小按钮和输入框 | 24 或 28 | 高度乘 3/8；内容和焦点至少留 4 |

昵称和会员期限共用一个入口，展开后分别编辑。个人用量与归档行静止时透明，悬停表面使用同一套令牌。详情收起时正文固定；展开后正文、归档和日期共同滚动。

多条内容统一使用列表组件。总数超过每页上限才生成分页工具栏；单页列表不占分页空间。分页列表保留一页高度，切换末页时入口和分页位置稳定。

## 提示位置

首页状态提示覆盖其他账号第三行的完整区域，尺寸、圆角和悬停范围与该行相同。其余页面在实际底部操作栏上方留 8；没有底部操作栏时距面板底部 12。滚动区域为提示保留可达空间，键盘焦点优先显示。状态提示由独立组件管理，不改变内容卡片的位置。

## 接力选择

手动指定的下一棒是一次性持久选择：面板显示、手动接力和自动接力读取同一选择，切换并核验目标账号后清除。额度过期时先刷新指定账号；自动接力继续遵守参与账号设置。未指定时采用额度推荐排序。恢复后接力预约独立保留。

## 资料与系统操作

账号编辑、已保存资料和备份导入共享昵称与日期校验。备份解密后先构建限定字段的标准数据，再执行有恢复日志的事务。账号、工作区和用量身份必须对应，采集时间保持原值。导出、解锁、导入和卸载各自只有一个活动操作，退出导入页即释放已解锁资料。

卸载组件完成路径、程序和任务身份检查后才报告就绪。主程序确认交接后退出，卸载组件等待相关进程结束再清理。

## 更新通知

已安装程序启动后检查 GitHub 正式 Release，随后每 6 小时检查；连接失败在 15 分钟后重试。检查只读取发布元数据。Windows 托盘和面板提供进入版本更新页的入口，同一版本的同一份程序只主动通知一次；下载和安装由用户发起。

## 验证

正式面板和离线 HTML 从同一组件构建。发布前检查完整场景目录的浅深色、两种材质、文字溢出、展开与分页、状态提示、键盘焦点和转场，再验证资料事务、接力选择、系统操作和冻结发布包。验证证据保存在本次任务 `_wip` 中。
